# Student-Mark-Analysis

## About
A simple Python command-line project to manage student records, calculate marks, generate grades, and identify the class topper.

## Features
1. Add student details
2. Display all student records
3. Search student by roll number
4. Calculate total marks and average
5. Assign grades automatically
6. Identify the class topper
7. Save student records using CSV file storage
8. Validate marks and prevent duplicate roll numbers

## Technologies Used
- Python 3
- CSV file handling

## How to Run
1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in a terminal.
4. Run:
   ```bash
   python student_marks.py
   ```
