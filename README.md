# student-mark-analysis
A simple python project to manage student records, calculate marks, generate grades, and identify the class topper.
#Features
1.Add student details
2.Display all student records
3.Search student by roll number
4.Calculate total marks and average
5.Assign grades automatically
6.Identify the class topper
7.Save student records using CSV file storage
8.Validate marks and prevent duplicate roll numbers
#Technology used
1.python
2.CSV file handling
#How to run
1.Install python on your computer
2.Download or clone this repository
3.Open the project folder
4.Run the following command:
      python student_marks.py
#Learning outcome
This project demonstrates python functions,loops,conditional statements, lists, dictionaries, exception handling and CSV file operations
